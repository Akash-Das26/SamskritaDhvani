Workflow Step 01

1. Starting the Demo

The entire demo runs offline on cached synthetic models and reference takes with one command:

BASH TERMINAL PORT 8000 
# From the project root (SamskritaDhvani/)
.venv/bin/python -m demo.server          # http://127.0.0.1:8000

To seed all 25 reference WAV takes and build the calibration scale: 

.venv/bin/python -m demo.prepare_demo_data    # copies 25 WAV files
.venv/bin/python -m demo.build_demo_calibration --force

Workflow Step 05

5. Video Analysis Pipeline

Processes uploaded video recordings (≤30 min, ≤512 MB) through a multi-stage computer vision workflow:

1. Keyframe Gallery

Adaptive temporal sampling of salient visual anchors.

2. Scene Timeline

PySceneDetect content-aware cuts with histogram verification.

3. Motion Energy

Frame-difference motion grid, heatmap and per-second activity.

4. Object Tracking

HOG person detector + centroid association fallback (no YOLO, no model download).

5. Video Summary

Per-shot trims concatenated to 25% of the source, capped at 90 s.

6. Job Polling API

Non-blocking background thread with progress telemetry.
